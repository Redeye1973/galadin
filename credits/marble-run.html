Marble Run

Wie en wat er in dit spel zit.

Beeld en code

Het beeld is gemaakt met een AI-beeldgenerator voor pixelart en daarna door ons bijgewerkt. De code is geschreven met hulp van AI-assistenten (Claude van Anthropic), onder regie en met toetsen door de maker.
